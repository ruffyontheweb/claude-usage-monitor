# claude-usage-monitor

Local monitoring for Claude Code usage on node0 (an LGTM container fed by Claude Code's OpenTelemetry export, with a
Grafana dashboard), plus a session-handoff tool: a status line showing conversation size, hooks that nudge a handoff at
natural breaks once the conversation is large, and a `/handoff` skill that writes a one-page note for a fresh session.
Design: `docs/specs/2026-11-05-session-handoff-design.md`.
